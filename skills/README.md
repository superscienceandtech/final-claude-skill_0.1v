# Skills

This repository holds the first canonical implementation skill.

## Canonical skill

- [implementation](./implementation/implementation.md) — a provider-neutral workflow for carrying out engineering tasks safely and verifiably.

## Scope

This repository intentionally limits itself to the implementation skill and the minimal supporting documentation needed to make it usable.

## Design principles

- Keep the workflow reusable across providers and repositories.
- Require inspection and verification before claiming completion.
- Avoid hidden assumptions, scope creep, and unapproved architecture decisions.
- Separate implementation from independently verified acceptance.
